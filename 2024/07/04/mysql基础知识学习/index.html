MySQL 基础知识学习

1. MySQL 简介

  • MySQL 是一个开源的关系型数据库管理系统（RDBMS）。

  • 使用 SQL（Structured Query Language，结构化查询语言） 来管理数据库。

  • 特点：

    • 开源免费
    • 跨平台
    • 支持大规模数据存储
    • 广泛应用于 Web 开发

2. 数据库基本概念

  • 数据库（Database）：存放数据的仓库。
  • 表（Table）：数据库中的基本存储单位，类似 Excel 表格。
  • 行（Row / Record）：表中的一条数据。
  • 列（Column / Field）：表中的一个字段。
  • 主键（Primary Key）：唯一标识一条记录。
  • 外键（Foreign Key）：表与表之间的关联。

3. 常用 SQL 分类

  • DDL（Data Definition Language，数据定义语言）

    • 创建、修改、删除数据库和表

  • DML（Data Manipulation Language，数据操作语言）

    • 插入、更新、删除数据

  • DQL（Data Query Language，数据查询语言）

    • 查询数据

  • DCL（Data Control Language，数据控制语言）

    • 用户权限管理

10. 常见问题

  1. MySQL 区分大小写吗？

    • Windows：不区分大小写
    • Linux：区分大小写（表名、数据库名）

  2. NULL 和空字符串的区别？

    • NULL 表示没有值

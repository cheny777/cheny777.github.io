常见的mysql面试题

MySQL 常见面试题总结

1. 基础知识

  • MySQL 存储引擎有哪些？区别是什么？

    • InnoDB：支持事务、行级锁、外键，默认存储引擎。
    • MyISAM：不支持事务，表级锁，查询快，适合读多写少。
    • Memory：数据存储在内存中，速度快但断电丢失。

  • varchar 和 char 的区别？

    • char(n)：定长，浪费空间但效率高。
    • varchar(n)：变长，节省空间但查询略慢。

  • int(11) 中的 11 有什么含义？

    • 仅表示显示宽度（与 ZEROFILL 搭配使用），与存储大小无关。

2. 索引相关

  • 索引的类型有哪些？

    • 普通索引（INDEX）
    • 唯一索引（UNIQUE）
    • 主键索引（PRIMARY KEY）
    • 复合索引（多个字段组合）
    • 全文索引（FULLTEXT）
    • 哈希索引（Memory 引擎支持）

  • 什么情况下索引会失效？

    • 使用 LIKE '%xxx'（前置模糊匹配）。
    • 对索引字段使用函数或运算（如 WHERE YEAR(date) = 2023）。
    • 隐式类型转换（如字符串与数字比较）。
    • 复合索引未满足最左前缀法则。

  • B+Tree 索引和 Hash 索引的区别？

    • B+Tree：范围查询、排序效率高。
    • Hash：等值查询快，但不支持范围和排序。

3. 事务与锁

  • MySQL 事务的四大特性 (ACID)

    • 原子性（Atomicity）
    • 一致性（Consistency）
    • 隔离性（Isolation）
    • 持久性（Durability）

  • 事务的隔离级别？

    • 读未提交（READ UNCOMMITTED）：可能脏读。
    • 读已提交（READ COMMITTED）：解决脏读，但可能不可重复读。
    • 可重复读（REPEATABLE READ，默认）：解决不可重复读，但可能幻读。
    • 串行化（SERIALIZABLE）：最高级别，性能差。

  • MySQL 中有哪些锁？

    • 全局锁：对整个库加锁。
    • 表级锁：如 LOCK TABLES。
    • 行级锁：InnoDB 支持，粒度小。
    • 意向锁：加速判断行级锁冲突。

4. 查询优化

  • 如何查看 SQL 执行计划？

    • 使用 EXPLAIN 或 EXPLAIN ANALYZE。

  • SQL 优化常见方法？

    • 避免 SELECT *，只取必要字段。
    • 建立合适的索引（遵循最左前缀法则）。
    • 使用批量插入而非逐条插入。
    • 分表分库，读写分离。
    • 使用 EXPLAIN 分析执行计划，避免全表扫描。

5. 日志与恢复

  • MySQL 常见日志类型？

    • 错误日志（error log）
    • 二进制日志（binlog，用于数据恢复和主从复制）
    • 重做日志（redo log，保证事务持久性）
    • 回滚日志（undo log，保证事务原子性）
    • 慢查询日志（slow query log，用于性能优化）

  • binlog 和 redo log 的区别？

    • binlog：逻辑日志，记录 SQL 语句或结果，用于数据恢复和主从复制。
    • redo log：物理日志，记录数据页的修改，用于崩溃恢复。

6. 主从复制与高可用

  • MySQL 主从复制的原理？

    1. Master 写 binlog。
    2. Slave I/O 线程读取 binlog 并写入 relay log。
    3. Slave SQL 线程读取 relay log 并执行。

  • 主从复制模式？

    • 异步复制（默认）。
    • 半同步复制。
    • 全同步复制。

7. 其他常见问题

  • 大表优化方案？

    • 分表分库。
    • 分区表（partition）。
    • 建立合适的索引。
    • 使用缓存（Redis）。
    • 归档历史数据。

  • 视图 (View) 的作用？

    • 封装复杂 SQL，提高复用性。
    • 限制访问权限。

  • 存储过程和函数的区别？

    • 存储过程可以返回多个值，适合批量操作。
    • 函数必须返回一个值，可在 SQL 中调用。

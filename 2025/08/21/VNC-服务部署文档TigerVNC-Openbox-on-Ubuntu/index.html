VNC 服务部署文档（TigerVNC + Openbox on Ubuntu)

VNC 服务部署文档（TigerVNC + Openbox on Ubuntu）

1. 概述

本文档提供在 Ubuntu 系统上使用 TigerVNC + Openbox 的轻量级 VNC 服务部署方案。

2. 环境准备

2.1 系统要求

  • 操作系统：Ubuntu 20.04/22.04
  • 用户权限：sudo 权限
  • 网络：开放 VNC 端口（默认 5901+）

2.2 安装依赖

bash
sudo apt update
sudo apt install tigervnc-standalone-server tigervnc-common openbox obconf -y

3. 安装与配置

3.1 设置 VNC 密码

bash
vncpasswd

3.2 配置 Openbox 启动脚本

bash
mkdir -p ~/.vnc
cat > ~/.vnc/xstartup <<’EOF’
!/bin/bash

unset SESSION_MANAGER
unset DBUS_SESSION_BUS_ADDRESS
exec openbox-session &
lxterminal & # 可选
tint2 & # 可选
EOF
chmod +x ~/.vnc/xstartup

3.3 启动临时会话

bash
vncserver :1 -geometry 1920x1080 -depth 24 -rfbport 5901 -xstartup ~/.vnc/xstartup

4. 系统服务配置

4.1 创建 systemd 服务

bash
sudo nano /etc/systemd/system/vncserver@.service

粘贴以下内容：
ini
[Unit]
Description=TigerVNC Server (:%i)
After=syslog.target network.target

[Service]
Type=simple
User=
WorkingDirectory=/home/
ExecStart=/usr/bin/vncserver :%i -geometry 1920x1080 -depth 24 -rfbport 590%i -localhost no -xstartup /home//.vnc/xstartup
ExecStop=/usr/bin/vncserver -kill :%i
Restart=on-failure

[Install]
WantedBy=multi-user.target

4.2 启用服务

bash
sudo systemctl daemon-reload
sudo systemctl start vncserver@1.service
sudo systemctl enable vncserver@1.service

5. 防火墙与安全

5.1 开放端口

bash
sudo ufw allow 5901/tcp
sudo ufw reload

6. 连接测试

使用 VNC 客户端连接：

  • 地址：<服务器IP>:5901
  • 密码：vncpasswd 设置的密码

7. 常见问题排查

7.1 Openbox 未启动

bash
which openbox-session
sudo apt install –reinstall openbox obconf

8. 卸载 VNC

bash
sudo systemctl stop vncserver@1.service
sudo systemctl disable vncserver@1.service
sudo rm /etc/systemd/system/vncserver@.service
sudo apt remove tigervnc-standalone-server openbox -y
rm -rf ~/.vnc

9. 附录

9.1 常用命令

功能 命令
启动会话 vncserver :1 -geometry 1920x1080
关闭会话 vncserver -kill :1
